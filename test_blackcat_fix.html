🧪 Teste de Verificação - Correção Blackcat PIX

📋 Objetivo: Verificar se a correção do bug de localStorage está funcionando corretamente.

🐛 Bug Original: Quando um novo cliente gerava um PIX, os dados de todos os clientes anteriores eram sobrescritos com as informações do novo cliente.

✅ Correção Implementada: Agora cada transação usa chaves específicas no localStorage (ex: customer_data_TX123 ao invés de customer_data).

Teste 1: Simulação de Múltiplas Transações

Este teste simula dois clientes diferentes gerando PIX simultaneamente.

Teste 2: Verificar Isolamento de Dados

Verifica se os dados de cada transação estão isolados e não se misturam.

Teste 3: Visualizar localStorage

Mostra todas as chaves relacionadas a transações no localStorage.

Teste 4: Simular Fluxo Completo

Simula o fluxo completo: checkout → pagamento → escolha de entrega
